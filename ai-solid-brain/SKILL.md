# ИИ-чат через Chrome: Qwen → Coder → DeepSeek

## Приоритет выбора чата
1. **Qwen (обычный чат)** — `chat.qwen.ai`, вкладка «Qwen Studio». Основной вариант для любого вопроса. Модель вверху по центру (напр. Qwen3.x-Plus).
2. **Coder** — `coder.qwen.ai`, отдельная вкладка «Qwen Coder». Для задач про КОД: написать код, экспорт/деплой в GitHub. Открывается из левого меню чата пункт **Coder**, или прямо по ссылке. Слева свой список задач («Все задачи», сессии последних 7 дней).
3. **DeepSeek** — `chat.deepseek.com`. Fallback, если Qwen не отвечает / завис.

## Особенности работы с GUI
- После каждого действия, кроме постановки каретки (она мигает её может быть не видно на скриншоте), выполнить selfshot (перед отправкой текста и после, свернуть, развернуть, открыть сайт, закрыть приложение и тому подобное).

## Особенность Qwen: АВТОКОПИРОВАНИЕ ответа в буфер (ключевое отличие от deepseek)
- После завершения ответа его текст **автоматически попадает в буфер обмена**, копировать ничего не надо.
  Проверено 2026-09-01 на обычном чате: вопрос «Response one word only: QWEN» → в `xclip` сразу было «QWEN», кнопку не жали.
- Ответы короткие (без веб-поиска) генерируются за ~8–14 с.
- **Ответы С ИСТОЧНИКАМИ / веб-поиском**: Qwen долго ищет по вебу, затем генерирует — суммарно 60–120+ с. Используй `sleep 100` (минимум) перед проверкой буфера.
- Буфер заполняется ПОСЛЕ конца ответа.

### Как читать ответ (Qwen)
```bash
# после отправки вопроса и паузы на генерацию:
xclip -selection clipboard -o | head -c 200   # просмотр начала
xclip -selection clipboard -o                 # весь ответ в текст/контекст
```
- Если буфер пуст — либо ещё идёт генерация (дождись и перечитай), либо это Coder-ответ без автокопии → смотри Fallback.

## Задаём вопрос
1. Активная вкладка чата: клик в поле ввода (обычный Qwen ~ `500 547`, центр; Coder — большое поле «Кодировать свою креативность здесь» по центру).
2. `xdotool type --clearmodifiers "<вопрос>"` — ввод отдельной командой, НЕ склеивать с проверкой через `;`.
3. Отправить: `xdotool key Return`.
4. Пауза на генерацию: короткий ответ без поиска — `sleep 15`; **вопрос с поиском по вебу (источники [[N]]) — `sleep 100` минимум**. Не ставь timeout < 120 s на bash-вызов, иначе команда упадёт раньше готовности.
5. Читать буфер `xclip -selection clipboard -o` (Qwen) — ответ готов к работе как текст.

### Совет по формулировке
- Проси только основные моменты, тезисно, с примерами — контекст не забивается длинной отпиской.

## Fallback: автокопии нет / буфер пуст
Применяется к **Coder** и к любому случаю, когда `xclip` пуст после паузы:
- Сделай selfshot → посмотри на экран: есть ли ответ, идёт ли генерация.
- Кнопка копирования внизу ответа (два квадратика): левее — круглая стрелка, лайк/дизлайк, «поделиться». Нажми её, затем `xclip -selection clipboard -o`.
- Длинный ответ: кнопки может не быть в видимой области → фокус кликом на центр страницы, page down ~30 раз, ищи кнопку.

## Coder — отдельная среда (агент), НЕ стрим-чат
- **Куда вводить**: вопросы, касающиеся ПРОГРАММИРОВАНИЯ (написать код, скрипт, проект) → отправлять сюда. Обычный чат Qwen (`chat.qwen.ai`) — для остальных вопросов.
- Кнопка «Веб-приложение» в поле ввода Coder: по умолчанию включена (голубой). При написании обычного скрипта её нужно ОТКЛЮЧАТЬ, чтобы не заставлять модель строить web-app. Отключение: крестик ✕ на ЛЕВОМ краю кнопки «Веб-приложение» — он НЕВИДИМЕН до наведения курсора/клика в ту область (просто клик по левому краю кнопки). (доработать)
- `coder.qwen.ai`. Это кодинг-агент со своей рабочей средой: на вопрос он **запускает Shell/репозиторий**, а не просто печатает ответ. Слева свой список задач («Все задачи», сессии 7 дней), справа панель вкладки Разница / Предварительный просмотр / Войти, кнопки «Опубликовать на GitHub» / «Репозиторий». Кнопка копирования у вывода сверху-справа панели.
- Автокопирование в буфер в Coder **НЕ проверено** (2026-09-01: среда была занята/не работала — генерация шла как shell, буфер не обновился). Поэтому в Coder по умолчанию считаем автокопии нет:
  1. selfshot → убедиться, что агент закончил работу (стопка «работает · NNs» исчезла).
  2. `timeout 3 xclip -selection clipboard -o` → если пусто/маркер — читать ответ с экрана (selfshot) или нажать кнопку копирования в панели вывода.
- Если Coder завис / не отвечает вообще — это баг среды, а не скилл: fallback на обычный Qwen чат.

## DeepSeek (fallback)
- Отдельно открыть/продолжить чат: `https://chat.deepseek.com/` в Chrome; новый чат — кнопка слева сверху или заново со ссылкой.
- Автоскролла нет, индикатора готовности нет. Кнопка копирования ВНИЗУ каждого ответа (два квадратика), не сбоку.
- «Обрезанный текст» ≠ конец ответа: если есть кнопка копирования и блок сайтов-источников — ответ готов; их отсутствие → ответ ещё рендерится, листай вниз.

## Как отличить Qwen от DeepSeek в буфере/на экране
- В адресной строке: `chat.qwen.ai` / `coder.qwen.ai` = Qwen; `chat.deepseek.com` = DeepSeek.
- У Qwen автокопия в буфер, у DeepSeek её нет — всегда кликай кнопку копирования (кроме случаев где ответ короткий и видно целиком).
