# Work — интерактивное окно оркестратора

Свободное окно для интерактивной работы (REPL, TUI, ручные команды). Скрипт —
просто воркер `exec bash --login`: при необходимости легко заменяется на любой
другой запуск (например, конкретный REPL), не трогая `MAIN-HOUSE-START`.

## Запуск

Команда в PATH (`~/.local/bin/work`). Вручную:

```bash
work
```

Нормально поднимается автоматически: `MAIN-HOUSE-START` создаёт окно
`MAIN-HOUSE:work` (последнее, idx 2) и запускает туда `work`. Окно свободно —
сюда можно слать `send-keys`, это единственное «живое» окно.
