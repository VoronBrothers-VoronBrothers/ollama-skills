# Selfshot — скриншот себе в tmux

Если перед тобой задача на зрение — сначала запусти скилл **enterwatch** (страховка: сам нажмёт Enter, если твоё сообщение зависнет в строке ввода).

Скрипт `scripts/selfshot.sh` делает скриншот всего экрана (spectacle) и отправляет путь к нему + задачу в свою tmux-сессию `orchestrator-this-is-your-own-tmux-send-pictures-here-with-task`.

## Запуск

```bash
# стандартная задача: «что ты видишь, загораживают ли окна»
nohup bash <skill_dir>/scripts/selfshot.sh > /dev/null 2>&1 &

# кастомная задача — первым аргументом
nohup bash <skill_dir>/scripts/selfshot.sh "найди кнопку Пуск и напиши координаты X Y по экрану 1920x1080" > /dev/null 2>&1 &
```

Запускать в фоне (nohup), иначе команда отменяется при ответе агента.

## Важно

- В скрипте зашита сессия `S="orchestrator-this-is-your-own-tmux-send-pictures-here-with-task"`. Если сессия называется иначе — поправь переменную S перед запуском.
- Задача для поиска координат: всегда просить координаты **по полному экрану 1920x1080**.
- Ответ придёт в очереди как `[Сообщение от самого себя] [Image #N] ...` — обрабатывай его, когда дойдёт.
- Клик по найденным координатам выполняй СТРОГО скриптом из скилла mouse-click (xdotool), не вручную или скриптом пайтон.
- Задача по обработке изображения это промежуточная задача, после выполнения продолжай основную задачу.
- Все клики мышью выполнять только через скилл mouse-click или через пайтон скрипт, ЗАПРЕЩЕНО кликать через xdotool.

## Урок из практики: ввод текста через xdotool — по одной команде
Ошибка 2026-09-01 (чат Qwen): `xdotool mousemove X Y click` упёрся в синтаксис (`click` требует номер кнопки), но из-за `;` следующие команды всё равно отработали, текст набрался, а я повторил ввод полностью → сообщение ушло дважды («Привет! Корот**Привет!**ко: ...»).
Правила:

1. Не склеивать ввод текста и проверку через `;` — используй `&&`, либо разбивай на отдельные команды bash-вызова.
2. После набора текста перед отправкой (Enter) снять selfshot или проверить содержимое поля.
3. sleep ≥5 c внутри одного tool-вызова рискованный (отмена) — короткие снапы + дозовые вызовы.
4. selfshot всегда nohup.
