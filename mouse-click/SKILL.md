# Клики мыши по координатам

Все клики выполняй ТОЛЬКО этим скриптом. Когда прислали координаты (X Y), выполни клик:

```bash
python3 ~/.ollama/skills/mouse-click/scripts/click.py X Y [delay_ms] [--repeat N] [--gap M]
```

Параметры:
- `X Y` — координаты цели, ОБЯЗАТЕЛЬНЫ (левый верхний угол экрана = 0 0).
- `delay_ms` — задержка между «доводом» курсора и самим кликом; по умолчанию **300** мс. Если курсору нужно "докатиться" до элемента или UI обновится, поставь больше (500–1000). Опциональный параметр: можно не писать.
- `--repeat N` — сколько раз нажать кнопку «1». По умолчанию 1 (один клик). Двойной клик = **2**, тройной = 3. Не задан → один левый клик.
- `--gap M` — интервал между повторными кликами в мс; по умолчанию **150**.

## Двойной/множественный клик

Два или больше клика одним вызовом через `--repeat N`. Важно: интервал `--gap` должен быть меньше порога KDE (~400 мс), иначе повторные нажатия не распознаются как двойной/тройной клик, а просто как отдельные одиночные. Поэтому дефолтный 150 мс безопасен; если ставишь свой --gap, держи его < ~400.

```bash
# двойной клик по (500 300)
python3 ~/.ollama/skills/mouse-click/scripts/click.py 500 300 --repeat 2
# тройной клик с интервалом 120 мс, перед заходом на элемент — задержка 800 мс
python3 ~/.ollama/skills/mouse-click/scripts/click.py 500 300 800 --repeat 3 --gap 120
```

После каждого вызова скрипт печатает строку подтверждения, сверяй её с задуманным:
`click X Y (preNms, xN, gapMms)` — pre = задержка до клика, x N = число нажатий, gap M = интервал.

## Несколько кликов по разным точкам

Выполняй каждый клик отдельной командой, в заданном порядке:

```bash
python3 ~/.ollama/skills/mouse-click/scripts/click.py 500 300
python3 ~/.ollama/skills/mouse-click/scripts/click.py 520 340 600
```

После клика при необходимости проверь результат скриншотом (скилл selfshot).
