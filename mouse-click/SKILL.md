# Клики мыши по координатам

Когда тебе прислали координаты (X Y), выполни клик:

```bash
python3 ~/.ollama/skills/mouse-click/scripts/click.py <x> <y> [delay_ms]
```

- `<x> <y>` — координаты цели (обязательно).
- `delay_ms` — задержка перед кликом по умолчанию 300 мс. Если курсору нужно "докатиться" до элемента или UI обновится, поставь больше (500–1000).

Скрипт двигает курсор через xdotool, ждёт delay и делает левый клик.

## Несколько кликов

Выполняй по одному на команду, в порядке отправления:

```bash
python3 ~/.ollama/skills/mouse-click/scripts/click.py 500 300
python3 ~/.ollama/skills/mouse-click/scripts/click.py 520 340 600
```

После клика при необходимости проверь результат скриншотом (скилл selfshot).
