# Browser chat — визуальный алгоритм (основной путь)

ПРИНЦИП: оркестратор ВЕДЁТ глазами. Скрин → смотрю → решаю координаты сам → xdotool. Скрипты из `Скрипты_ИИ/browser_chat/` — запасной вариант, если визуальный цикл буксует.

## Цикл (E2E-проверено 2026-08-24 ~10:30)

0. **Скрин desktop** → `spectacle -b -f -o /tmp/desk.png` → `show_image.sh /tmp/desk.png $(консольный PID)` → следующий turno я смотрю.
   - Хром мёртв (обычно — мы его не держим)? Тогда шаг 1 обязательный. Окно есть? — пропустить 1, сразу к 2.
1. **Клик Chrome в доке** ≈(167,1051) → `xdotool mousemove 167 1051 click 1` → sleep 4-7 c → скрин.
   - Хром стартует с google.com (наш профиль). Ждать, пока страница отрисовалась.
2. **Скрин Chrome** → смотрю: открыта ли уже Дипсик-страница? Если да — к 4.
3. **Клик закладки «DeepSeek - Into t...»** ≈(665,104) (координаты с актуального скрина!) → sleep 5 → скрин.
   - Страница загружена = виден поле «Message DeepSeek» и фокус уже в поле ввода (курсор — сразу после загрузки).
4. **Ввод + Enter** сразу: `xdotool type --delay 40 "<вопрос>"` → sleep 0.4 → `xdotool key Return`.
   - ДО ввод/клик сделать `xdotool windowactivate --sync $W` (W = последний видимый google-chrome) — фокус окна обязателен, иначе пьеза в консоль.
5. **Визуальное ожидание**: sleep 10-15 c (зависит от длины вопроса) → скрин. Ответ готов = текст под моим сообщением, иконки действий под ответом, статус «AI-generated». Если печатает ещё — дождав ещё 5 c и перескрин.
6. **Copy**: под ответом ряд иконок, Copy = самая левая (две наложенные квадратики). Y зависит от длины ответа — ТОЛЬКО с актуального скрина. Для короткого ответа «NN»: ≈(730,364).
   - ПЕРЕД кликом: `xclip -selection clipboard < /dev/null` (stale-буфер). После: sleep 1, `xclip -selection clipboard -o`. Здоровый ответ ≥50 B; мусор/пусто → переприцель с нового скрина.
7. **Отчёт** по тексту из буфера. В конце вернуть фокус в консоль: `/home/voron/Документы/VB-ollama/Скрипты_ИИ/focus_consolidate.sh`.

## Правила (выученные)

- **Окно**: `W=$(xdotool search --onlyvisible --classname google-chrome | tail -1)`. Хром чата = точно `google-chrome`; VPN Prizrak = `google-chrome-stable` — substring не путать.
- **Скрин**: `spectacle -b -f -o <file>` → 1920×1080, пиксели = экранные координаты мыши 1:1.
- **Видение**: `show_image.sh <img> <консольный_PID>` → картинка прилетает вложением в следующем turno той же сессии. PID консоли оркестратора берём из окна (заголовок «ollama — Konsole») или держим в /tmp/orch-note.md.
- **Фокус**: перед каждой цепочкой xdotool — `windowactivate --sync $W`. После каждого действия с браузером — фокус назад в консоль.
- **Copy в шапке код-блока НЕ кликать** — скопирует только код (симптом: ~400-500 B при длинном ответе).
- **Хром без CDP** (`--remote-debugging-port` нет) — текст только copy/зрением.
- **Новый вопрос = новый чат**: если Дипсик уже открыт с чужим контекстом — сначала «New chat» ≈(93,213), потом ввод.
