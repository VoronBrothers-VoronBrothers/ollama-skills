# Qwen.ai — наработки (chat.qwen.ai)

## Статус: частично работает, блокируется антиботом

Логин и отправка сообщения проходят. **Ответ модели не приходит** — Qwen.ai подставляет
антибот-проверку для автоматизированного браузера. Обойти скриптом нельзя.

## Что проходит

1. Навигация на `https://chat.qwen.ai`
2. Клик по кнопке «Войти» (button, text="Войти") → переход на `/auth`
3. Ввод email: `input[name=email]`, type=text, placeholder="Введите вашу электронную почту"
4. Клик "Войти с паролем" (button) → появляется password input
5. Ввод пароля: `input[name=password]`, type=password
6. Клик "Войти" (button) → успешный логин, возврат на `/`
7. Находится textarea (placeholder="Спросить Qwen")
8. Ввод сообщения через React nativeSetter + dispatch input
9. Клик `button.send-button` → URL меняется на `/c/<uuid>`

## Что НЕ проходит

- Ответ модели не появляется в DOM после 30+ секунд
- Селекторы `[class*=message]`, `[data-testid*=message]` видят только пользовательское сообщение
- Антибот-защита блокирует генерацию без ручного прохождения CAPTCHA
