# Selfshot — картинка в tmux

Один входной скрипт, модульная система. Скриншот экрана ИЛИ любой файл по пути → необработываем (сетка, оверлей) → отправляем себе в tmux с задачей.

## Запуск

```bash
# Снять экран и отправить (без сетки)
nohup bash ~/.ollama/skills/selfshot-2/scripts/SELFSHOT > /dev/null 2>&1 &

# Снять экран + малая сетка (ориентир)
nohup bash ~/.ollama/skills/selfshot-2/scripts/SELFSHOT --scale "найди кнопку калькулятора, дай X Y (изображение 1920x1080)" > /dev/null 2>&1 &

# Снять экран + полная точная сетка (для кликов)
nohup bash ~/.ollama/skills/selfshot-2/scripts/SELFSHOT --full-grid "дай точные координаты для клика (изображение 1920x1080)" > /dev/null 2>&1 &

# Готовая картинка по пути + сетка
nohup bash ~/.ollama/skills/selfshot-2/scripts/SELFSHOT --scale /tmp/screen.png "координаты курсора? (изображение 1920x1080)" > /dev/null 2>&1 &

# Просто отправить файл без обработки
nohup bash ~/.ollama/skills/selfshot-2/scripts/SELFSHOT /home/voron/Изображения/photo.jpg "что на фото (изображение 1920x1080)" > /dev/null 2>&1 &
```

Аргументы:
- `--scale` — малая сетка: толстые линии каждые 200 px + оси. Для ориентира «где примерно»
- `--full-grid` — полная (точная) сетка: тонкие линии ~50 px, для точных кликов. Автоматически включает `--scale`, оба прописывать не нужно
- `/путь/к/файлу.png` — взять готовую картинку (без этого — снять экран)
- `"текст"` — задача для модели. **Важно:** указывай разрешение изображения в задаче (по умолчанию `1920x1080`), это повышает точность координат

## Модули

В скрипте `SELFSHOT` есть массив:

```bash
MODULES=(
  "service:cursor-overlay"    # плашка координат мыши (вкл до снимка, выкл после)
  "transform:grid-scale"      # сетка на картинке (работает только с --scale)
)
```

**Приложить модуль:** добавить строку `"тип:имя"` в массив. Скрипт лежит в `scripts/имя.py`.  
**Отключить:** закомментировать или удалить строку.

Типы:
- `service` — фоновый процесс (включается до скриншота, выключается после)
- `transform` — принимает картинку, отдаёт обработанную (работает при `--scale`)

## Файлы скилла

| Файл | Роль |
|------|------|
| `scripts/SELFSHOT` | Входной скрипт. Оркестрация: PRE → CAPTURE → TRANSFORM → SEND → POST |
| `scripts/cursor-overlay.py` | Управление оверлеем (start/stop). «Глупый» — не знает где работает |
| `scripts/cursor-overlay-worker.py` | Воркер: рисует зелёную плашку с X,Y рядом с мышкой |
| `scripts/grid-scale.py` | Рисует сетку с осями. Вход: путь к png. Выход: путь к `_scale.png` |

## Важно

- Запускать через `nohup ... &`, иначе отменяется при ответе агента.
- Сессия tmux зашита: `orchestrator-this-is-your-own-tmux-send-pictures-here-with-task`.
- Клик по найденным координатам — только через скилл **mouse-click**.
- Красный квадрат в левом верхнем углу плашки — это **примерный ориентир** расположения курсора мыши. Это НЕ точка, куда произойдёт клик. Клик идёт по координатам X Y из текста плашки, а красный квадрат лишь визуально показывает «примерно здесь». Имей в виду: реальная горячая точка мыши может отличаться от положения квадрата на ±3–5 px.
- Ответ приходит в очереди как `[Сообщение от самого себя] [Image #N] ...`
