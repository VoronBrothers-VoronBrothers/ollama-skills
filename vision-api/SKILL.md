# Зрение

Одна команда, два режима. Для координат элементов → скилл **accessibility-tree**, не этот.

## Использование

```bash
# Что сейчас на экране (авто-скриншот с плашкой курсора)
python3 ~/.ollama/skills/vision-api/scripts/ask.py "вопрос (изображение 1920x1080)"

# Существующее изображение
python3 ~/.ollama/skills/vision-api/scripts/ask.py /tmp/photo.png "опиши что видно (изображение 1920x1080)"
```

> **Важно:** в задаче для модели всегда указывай разрешение изображения (по умолчанию `1920x1080`). Это повышает точность координат и описаний.

### Примеры

```bash
# Проверить результат действия
python3 ~/.ollama/skills/vision-api/scripts/ask.py "Открылось ли окно с ошибкой? Какой текст? (изображение 1920x1080)"

# Посмотреть на сохранённый файл
python3 ~/.ollama/skills/vision-api/scripts/ask.py /home/voron/Изображения/foto.jpg "Что на фото? (изображение 1920x1080)"

# Без вопроса — просто описание
python3 ~/.ollama/skills/vision-api/scripts/ask.py
```

## Как работает

| Режим | Триггер | Что делает |
|-------|---------|-----------|
| **AUTO** | Первый аргумент не файл | Оверлей → скриншот → модель → выкл оверлей |
| **FILE** | Первый аргумент — путь к файлу | Файл → модель (без оверлея) |

## Скрипты

| Файл | Роль |
|------|------|
| `ask.py` | Точка входа. Определяет режим, вызывает остальные. |
| `ask_old.py` | Отправляет картинку + вопрос в vision-модель (Ollama). |
| `cursor_overlay.py` | Плашка с X,Y координатами мыши на экране. |

## Технические детали

- Модель: `vision` (/home/voron/Документы/VB-ollama/Prompts-AI/Modelfile_vision) через Ollama localhost:11434

- Скриншот в AUTO режиме сохраняется в `/tmp/vision_api_screen.png`

## Альтернатива: чтение текста через буфер обмена

Когда vision API недоступен (таймаут, RAM занята) или нужен **дословный текст** без OCR-ошибок:

```bash
# Выделить всё в активном окне и скопировать
xdotool key ctrl+a
sleep 0.5
xdotool key ctrl+c
sleep 1
# Прочитать из буфера
xclip -selection clipboard -o
```

Работает в Chrome, Writer, терминале — везде где есть текстовый контент.
Точнее vision: нет галлюцинаций OCR, полный текст без обрезки.
