# model-boot-switch — запуск другой модели оркестратора

Смена модели, на которой работает оркестратор (типово — апгрейд кванта). Система: `ollama_console.sh` хардкодит имя модели на строке ~76 (`xdotool type ... "qwen3.8-orchestrator"`), `restart_self.sh` запускает его через `BOOT=`.

## ШАГ 1 — выбор источника
- `ollama list` + `grep FROM` текущий Modelfile (верх, в комментариях лежат все доступные кванты: iq2_xxs/iq3_xxs/iq4_xs/q5_K_M/q8_0).
- Оцени VRAM/RAM: квант должен помещаться с учётом ping-pong (одна крупная модель в памяти за раз — см. скилл ollama-safe-call).

## ШАГ 2 — создать новую модель (НЕ перезаписывая старую)
1. Скопировать Modelfile: `cp Modelfile_..._promt_2 Modelfile_..._q5` (имя с квантом).
2. В копии раскомментировать нужную строку `FROM ...:q5_K_M`, остальные закомментировать.
3. `ollama create qwen3.8-orchestrator-q5:latest -f <копия>` — имя новой модели отличает от текущей (безопасность: старый остаётся).

## ШАГ 3 — проверить новую модель
- `ollama list` — размер совпадает с ожидаемым квантом.
- Тест ответа через скилл **ollama-safe-call** (фон + polling; учти cold-load ~минуту и eviction текущей модели).

## ШАГ 4 — новый boot-скрипт
1. `cp ollama_console.sh ollama_console_q5.sh` (имя = квант).
2. В копии заменить имя модели в строке xdotool type (`qwen3.8-orchestrator` → `qwen3.8-orchestrator-q5`).
3. `sed -i`/edit в `restart_self.sh`: `BOOT="...ollama_console_q5.sh"`.

## ШАГ 5 — перезапуск (чекпоинт обязателен!)
1. Записать `state.md` (задача, сделано, следующий шаг = «проверить новый квант в новой сессии»).
2. Dry-run: `DRY_RUN=1 bash restart_self.sh` — проверить лог.
3. `rm -f "$TASKS/.restart_count"` (затворник) → `setsid bash restart_self.sh </dev/null >/tmp/restart.log 2>&1 &`
4. Новая сессия: проверить, что работает именно новое квант (размер/поведение), обновить state.md, удалить `.restart_count` при успехе.

## Откат
- `BOOT=` вернуть на исходный boot-скрипт; старая модель не удаляется — TUI просто поднимет её.
- Ошибка после перезапуска: удалить `.restart_count`, отредактировать BOOT обратно, повторить restart.

## Правила
- НИКОГДА не перезаписывай текущий Modelfile/boot-скрипт — только копии (откат = один sed).
- Каждую команду `ollama create`/тест выполняй и проверяй сам (размер в байтах, текст ответа).
- После успешного переключения: старое квант можно оставить (`ollama rm` только по решению пользователя).
