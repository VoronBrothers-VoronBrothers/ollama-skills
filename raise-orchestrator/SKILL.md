# Скилл: raise-orchestrator

Чтобы поднять оркестратора — выполни в bash одну команду:

```bash
raise-orchestrator
```
Для сохранения памяти оркестратор прописывает задачи в `/home/voron/Документы/VB-ollama/Папка заданий для AI/tasks.md`.
Скрипт сам всё сделает: если tmux-сессия `orchestrator-this-is-your-own-tmux-send-pictures-here-with-task` существует — убьёт её, затем создаст заново, запустит ollama TUI, выберет модель orchestrator и отправит задачу прочитать `/home/voron/Документы/VB-ollama/Папка заданий для AI/tasks.md`.

Проверка: в выводе должно быть `OK — оркестратор запущен, задача отправлена.`
Если ошибка — покажи вывод скрипта.

## Выживание после сбоя / перезагрузки видеопамяти (self-respawn)

Скилл спроектирован так, чтобы оркестратор мог пережить потерю GPU/VRAM: память живёт на диске в `tasks.md` (+ `/home/voron/Документы/VB-ollama/vb-ollama-long-memory/`), а возродить его может CPU-помощник.

### Что оркестратор делает сам (обязательно, до сбоя или перед перезапуском):
1. **Прописывает сам себе задачу и состояние**: в `tasks.md` фиксирует текущую задачу, следующий шаг и прогресс — так новый экземпляр продолжит работу с того же места.
2. Детали/откаты/история изменений — в `/home/voron/Документы/VB-ollama/vb-ollama-long-memory/`.
3. Если оркестратор сам инициирует перезапуск (или ожидает выключение) — сначала записать память, потом `raise-orchestrator`. Память до перезапуска — обязательное условие.

### Роль CPU-помощника (окно `MAIN-HOUSE:ollama-cpu`, модель MiniCPM5-2B-F16:latest):
- Помощник работает полностью в RAM/CPU и **не зависит от GPU**: если видеопамять недоступна (сбой, перезагрузка, ollama упал) — помощник продолжает жить.
- Он может сам выполнить `raise-orchestrator` через период неработоспособности с памятью/видеокартой: поднимет нового оркестратора, тот прочитает `tasks.md` и продолжит задачу, которую старый экземпляр успел записать.
- Схема выживания: **оркестратор пишет память → GPU/VRAM падает (помощник жив) → помощник запускает raise-orchestrator → новый оркестратор читает tasks.md и продолжает**.
