# zrenie_run — зрение конвейер

Скрипт: `/home/voron/Документы/VB-ollama/Скрипты_ИИ/зрение_всё_run.sh`

## Что делает
1. Минимизирует своё окно, делает скриншот `spectacle` в /tmp, разворачивает окно.
2. Кладёт путь к PNG в clipboard и проверяет совпадение буфера.
3. В tmux-сессии `zrenie_run` запускает `ollama run <модель>` (если сессии ещё нет) и присылает сообщение: `задача: <задача> | скриншот: <путь>`.

## Запуск
```bash
# по умолчанию: задача-заглушка, модель orchestrator:latest
/home/voron/Документы/VB-ollama/Скрипты_ИИ/зрение_всё_run.sh

# своя задача (первый аргумент)
/home/voron/Документы/VB-ollama/Скрипты_ИИ/зрение_всё_run.sh "что на экране?"

# своя модель (второй аргумент)
/home/voron/Документы/VB-ollama/Скрипты_ИИ/зрение_всё_run.sh "опиши" orchestrator:latest
```

## Проверить результат
Ответ модели — в tmux-сессии `zrenie_run`. Прочитать экран:
```bash
tmux capture-pane -t zrenie_run -p
```
(для живых сессий использовать скилл tmux)

## Замечания
- Сессия и модель живут между запусками: повторные вызовы — новый скрин в тот же REPL, контекст сохраняется.
- Ошибки скрипт пишет сам: «скриншот не получен», «буфер не совпал или файла нет».
- Скрипт не ждёт ответа модели — только отправляет сообщение и завершается.
- Желательно выполнять регулярно если несколько задач на зрение >>> /clear внутри tmux-сессии `zrenie_run`
