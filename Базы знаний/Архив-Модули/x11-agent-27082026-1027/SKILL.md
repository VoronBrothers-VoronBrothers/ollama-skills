# x11-agent: запуск

Агент `x11_agent.py` лежит в папке проекта
`/home/voron/Документы/VB-ollama/GitHub ollama and others/Цель - зрение, с нажатием кнопок, вводом текста`.
Модель видит фулл-скрин 1920x1080 с красной сеткой (шаг 50 px), отвечает одним JSON-действием; скрипт выполняет его pyautogui/xdotool.

Тонкости (киоск-режим, рецепты Google/DeepSeek, действия, ограничения, аварийный стоп) — в папке `память работы с инструментом/`. Только при сбоях — заглянуть; после нового сбоя — дописать.

## Запуск — всегда в tmux (ответы модели по минутам, интерактивный bash упрёт в таймаут)

```bash
# 0) убрать предыдущего агента и старую сессию (раздельно! pkill не должен быть в той же строке, что и запуск)
pkill -f "[x]11_agent.py"; tmux kill-session -t x11chk 2>/dev/null

# 1) сессия + пауза (гонка со стартом), затем одна команда: cd + запуск
tmux new-session -d -s x11chk
sleep 1.5
tmux send-keys -t x11chk "cd \"/home/voron/Документы/VB-ollama/GitHub ollama and others/Цель - зрение, с нажатием кнопок, вводом текста\" && DISPLAY=:0 python3 x11_agent.py \"задача... сделай done\" 8" Enter

# 2) ждать завершение (маркер в логе), затем прочитать
for i in $(seq 1 60); do tmux capture-pane -t x11chk -p | grep -q "завершил\|лимит\|ОШИБКА\|Traceback" && break; sleep 5; done
tmux capture-pane -t x11chk -p | sed '/^$/d' | tail -25
```

- Задача — один аргумент в кавычках, обязательно с условием остановки: «... — сделай done».
- Лимит шагов — второй аргумент (выше 8, по умолчанию 25). Модель 27B может молчать до 5 минут на шаг — не убивать.
- Всегда `DISPLAY=:0`.
- Убить: `pkill -f "[x]11_agent.py"` или Ctrl+C через send-keys.
- Следующая задача — тем же окном: ещё раз `tmux send-keys -t x11chk "DISPLAY=:0 python3 x11_agent.py \"...\" N" Enter`.
