# 2026-08-27: кинк-режим (full-screen браузер) и проверенные рецепты

## Кинк-режим — общее

- Открывать сайт: `google-chrome --start-maximized <url>` из tmux/bash.
- Полноэкранный вариант :
  `google-chrome --start-maximized https://chat.deepseek.com/`.
- **ВКОНЦЕ обязательно выйти из кинка**: агент делает `hotkey ["alt","f4"]`
  в последнем шаге, или из bash `pkill google-chrome`. Если Chrome остался —
  пользователь не понимает, закончился ли скрипт.

## Google: поиск с ИИ-режимом (проверено)

```bash
tmux send-keys -t x11chk "google-chrome --start-maximized https://www.google.com > /dev/null 2>&1 &" Enter
sleep 5
tmux send-keys -t x11chk "DISPLAY=:0 python3 x11_agent.py \"Google на весь экран. 1) В поле поиска (курсор уже там, НЕ кликай) напечатай: ВОПРОС. НЕ жми Enter! Кликни мышкой кнопку «Режим ИИ» — лупа с бликом, справа от поля поиска. 2) wait 15 секунд. Если есть кнопка развернуть результат — нажми её. Если есть строка меню «Режим ИИ / Все / Покупки / Картинки...» — кликни «Режим ИИ». 3) Если ответ открылся в том же поле поиска — пролистай страницу вниз и кликни кнопку копирования (самая нижняя левая, значок два прямоугольника). 4) Сделай done.\" 18" Enter
# ждать завершение → затем закрыть Chrome и прочитать буфер
pkill google-chrome; sleep 1; DISPLAY=:0 xclip -selection clipboard -o
```

Правила именно для Google:
1. Курсор уже в поле — не кликать.
2. После текста НЕ жать Enter — кнопка «Режим ИИ» (лупа с бликом) справа от поля, мышкой.
3. Кнопка развернуть результат → нажать её (если такая кнопка есть).
4. Строка меню «Режим ИИ / Все / Покупки / Картинки / Видео / Короткие видео / Карты / Ещё / Инструменты» → нажать «Режим ИИ» (если такая строка видна).
5. Если ИИ-режим открылся в том же поле — пролистать вниз и нажать копировать: самая нижняя левая кнопка, значок два прямоугольника. (Цель — передать результат поиска, а не выполнить строго алгоритм.)

## DeepSeek чат

```bash
tmux send-keys -t x11chk "google-chrome --start-maximized https://chat.deepseek.com/ > /dev/null 2>&1 &" Enter
sleep 8
tmux send-keys -t x11chk "DISPLAY=:0 python3 x11_agent.py \"DeepSeek на весь экран. 1) Напечатай (курсор уже в поле, НЕ кликай): ВОПРОС и нажми Enter. 2) wait 15 секунд — ответ. 3) ВСЕГДА scroll вниз до конца последнего ответа, потом кликни НИЖНЮЮ кнопку «копировать» (два квадратика, под всем сообщением). 4) done.\" 10" Enter
pkill google-chrome; sleep 1; DISPLAY=:0 xclip -selection clipboard -o
```

**Правило чтения/копии ответа DeepSeek:**
- **ВСЕГДА скроллить вниз до конца полученного ответа** — независимо от длины — и
  копировать НИЖНЕЙ кнопкой (два квадратика под всем сообщением). Она копирует
  всё сообщение в буфер, чтение: `DISPLAY=:0 xclip -selection clipboard -o`.
- Рядом с блоками кода есть СВОИ квадратики — они копируют только код. Не путать!
- Если нижние квадратики не видны на скриншоте — сообщение не долистано, сначала scroll.
- Продолжение той же сессии: просто клик в поле ввода внизу + type + Enter,
  новое сообщение уходит в ту же чат-сессию (проверено 2026-08-27).
