# 2026-08-27: действия модели, правила использования, ограничения, стоп

## Действия, которые понимает модель

- `click` / `double_click` (x,y в пикселях) — координаты по сетке на скриншоте.
- `type` — текст в активное окно через xdotool (кириллица работает).
- `press` (enter/esc/backspace/tab/up/down), `hotkey` (["ctrl","alt","t"]).
- `scroll` (amount, минус = вниз), `wait`, `done` (завершение).

## Правила использования

1. Задачу формулировать коротко и с понятным условием остановки:
   «Когда меню откроется — сделай done». Иначе агент упрётся в лимит шагов.
2. Перед запуском убедиться, что нет других x11_agent (pkill -f "[x]11_agent.py"),
   чтобы два агента не дёргали мышь одновременно.
3. Каждый шаг логируется: `🤖 решение: {...}` и `[руки] ...`.
4. Проверить результат после запуска: лог в tmux + буфер/скриншот.
5. После открытия меню/диалогов закрыть их (обычно Escape).
6. В задаче давать чистку помех: «Если на экране окна или диалоги, которые
   мешают выполнить задание (закрывают цель) — сначала закрой их (крестик /
   Esc / alt+F4), и только потом выполняй». Если закрытие не отработало — из bash:
   `pkill`, `xdotool key alt+F4`.
7. alt+F4 в Chrome может вызвать диалог «Закрыть?» — окно надёжнее убивать
   из bash: `pkill google-chrome`.
8. Цель последних действий — показать себя или убрать мешающие окна; пользователь
   должен видеть, что всё завершилось, иначе он будет вечно ждать окончания
   процесса, так как не видит консоль.

## Остановка и безопасность

- Аварийный стоп: резко переместить мышь в правый нижний угол экрана
  (в пределах 15 px от края). Проверено 2026-08-26: скрипт ловит его перед
  каждым шагом и действием.
- Ctrl+C — штатная остановка. Лимит шагов — по умолчанию 25, задаётся вторым аргументом.
- Скрипт сам удаляет временные скриншоты после каждого шага.

## Если агент не запускается

1. `python3 -c "import ollama, PIL, pyautogui"` — пакеты
   (ollama, mss через `pip install --break-system-packages`).
2. `echo $DISPLAY` должен быть :0; иначе `DISPLAY=:0 python3 ...`.
3. Если модель молчит долго — она просто думает/генерирует (27B), не убивать раньше 5 минут.

## Ограничения

- Координаты работают при масштабировании KDE 100% (проверено: 1920x1080).
- Сетка шаг 50 px (GRID_STEP, константа в начале файла) — с шагом 100 модель
  сбивала y по нижней панели задач (~950 вместо ~1050).
- Модель плохо оценивает y для целей у краёв экрана — в задаче давать якорь:
  «иконки на y≈1050, не выше линии y=1000».
- Вкладки браузера не кликать (промах в адресную строку мутирует экран).
  Сменить вкладку: `hotkey ["ctrl", 2..9]` или Ctrl+Tab.
