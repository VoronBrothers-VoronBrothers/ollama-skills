# deepseek_chat — чат с DeepSeek (автоматизация)

## Назначение
Весь скрипт нужен для того, чтобы я (оркестратор) отправил запрос в DeepSeek и получил ответ: «спрятался/ку-ку» — это сворачивание/разворачивание МОЕГО окна (не Chrome), чтобы DeepSeek был на переднем плане.

## Быстрый старт
```
./chat_deepseek.sh "твой вопрос"     # по умолчанию "Привет"
```

## Как работает алгоритм (от начала до конца)

### Точка входа: `chat_deepseek.sh` "вопрос"

Запускает две ветки:
1. **Foreground** — `start_and_screenshot_deepseek.sh` (блокирующий, ждёт завершения).
2. **Background** — `paste_image_ai_from_clipboard_and_a_goal.sh` (nohup, отложенный).

---

### Ветка 1 — Foreground: `start_and_screenshot_deepseek.sh`

| # | Вызов | Что делает |
|---|-------|------------|
| 1 | `spryatalsya.sh` | Сворачивает окно локального ИИ(тебя) (спрятаться). |
| 2 | `dipsik.sh` & sleep 4 | Открает DeepSeek в Chrome, ждёт 4 с загрузки. |
| 3 | `type_text.sh "$QUERY"` | Клик по полю ввода (726,578) + ввод текста вопроса (необязательно, так как фокус уже в поле). |
| 4 | `press_enter.sh` + sleep 8 | Enter — отправить. Ждёт 8 с на генерацию ответа. |
| 5 | `screenshot.sh` | Скриншот экрана → PNG в `/tmp/` + в буфер (xclip) (для поиска кнопки копировать, может быть в будущем для чего-то другого). |
| 6 | `ku_ku.sh` | Поднимает окно локального ИИ(тебя) (покажись). |

---

### Ветка 2 — Background: `paste_image_ai_from_clipboard_and_a_goal.sh`

Запускается через `setsid ... __bg &`, терминал не блокирует. Защита от дубля (pgrep).

| # | Вызов | Что делает |
|---|-------|------------|
| 1 | `press_ins.sh` | Shift+Insert — вставить картинку из буфера (скриншот) в чат DeepSeek. |
| 2 | sleep 0.5 | Пауза. |
| 3 | `задача_в_буфер.sh` | Кладёт фразу-задачу в буфер (по умолчанию: «найти кнопку копировать»). |
| 4 | sleep 0.5 | Пауза. |
| 5 | `press_ins.sh` | Shift+Insert — вставить задачу из буфера. |
| 6 | `press_esc.sh` | Esc (отмена подсказки/автодополнения). |
| 7 | sleep 2 | Ждёт обработки. |
| 8 | `press_enter_vvod.sh` | Enter — отправить сообщение ИИ. |
| 9 | `spryatalsya.sh` | Сворачивает окно локального ИИ(тебя) (спрятаться). |

---

### Визуальный цикл (оркестратор + зрение)

После выполнения веток оркестратор (AI) получает скриншот и:
1. **Видит** картинку — находит координаты нижней кнопки «копировать» (два квадратика) под ответом.
2. Вызывает: `python3 click_xy.py X Y` — клик мышью по найденным координатам.
3. Вызывает: `bash ku_ku.sh` — покажись (поднимает окно оркестратора).
4. Читает буфер: `xclip -selection clipboard -o` — текст ответа DeepSeek.

## Состав файлов

| Файл | Роль |
|------|------|
| `chat_deepseek.sh` | Оркестратор: foreground + background. |
| `start_and_screenshot_deepseek.sh` | Foreground-цепочка (6 шагов). |
| `paste_image_ai_from_clipboard_and_a_goal.sh` | Background-цепочка (9 шагов, setsid __bg). |
| `задача_в_буфер.sh` | Кладёт фразу-задачу в буфер. `$1` = своя задача. |
| `spryatalsya.sh` | Сворачивает окно локального ИИ (оркестратор). |
| `ku_ku.sh` | Поднимает окно локального ИИ (оркестратор, покажись). |
| `dipsik.sh` | Открает DeepSeek (новый чат) в Chrome. |
| `type_text.sh` | Клик + ввод текста в поле. |
| `press_enter.sh` | Enter. |
| `press_enter_vvod.sh` | Enter (вариант с задержкой). |
| `press_ins.sh` | Shift+Insert (вставка из буфера). |
| `press_esc.sh` | Esc. |
| `screenshot.sh` | Скриншот → `/tmp/` + буфер. |
| `click_xy.py` | Клик мышью по координатам X Y (pyautogui). |

## Как задать свою задачу
```
./задача_в_буфер.sh "своя задача"
```
Или передать аргумент в `chat_deepseek.sh` — текст уйдёт в поле ввода.
По умолчанию фоновая задача: «найти координаты нижней кнопки копировать (два квадратика)».
