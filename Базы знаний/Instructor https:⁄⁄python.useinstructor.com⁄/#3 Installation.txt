## Установка библиотеки `instructor`

Для установки выполните команду:

```bash
pip install instructor
```

### Зависимости

Библиотека `instructor` требует следующих пакетов:

- **`openai`** — официальный Python-клиент OpenAI API
- **`typer`** — фреймворк для создания CLI-приложений на основе аннотаций типов Python
- **`docstring-parser`** — парсер docstrings, преобразует их в структурированные данные (например, JSON Schema)
- **`pydantic`** — библиотека для валидации данных и управления настройками с использованием аннотаций типов

### Требования к среде

- Python ≥ 3.9
- `pip` (менеджер пакетов Python)

Если эти условия выполнены — установка проходит без дополнительных действий.
