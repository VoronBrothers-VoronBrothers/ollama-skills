## Структура репозитория Instructor

Репозиторий содержит основные компоненты библиотеки, инструментов и документации для работы с структурированными
выходными данными (structured outputs) через API-клиенты.

### Основные директории

- **`instructor/`**
Ядро библиотеки: содержит клиентские классы, адаптеры и вспомогательные утилиты для интеграции с LLM и генерации
структурированных данных.

- **`cli/`**
Реализация командной строки (CLI), используемой для:
- Управления заданиями (job management)
- Отслеживания использования (usage tracking)

- **`docs/`**
Исходные файлы документации, собираемые с помощью MkDocs. Содержит руководства, API-справочники и примеры.

- **`examples/`**
Практические примеры и «кулинарные книги» (cookbooks), демонстрирующие реальное использование библиотеки в
различных сценариях.

- **`tests/`**
Набор тестов и скрипты оценки, обеспечивающие корректность работы библиотеки:
- Unit-тесты
- Интеграционные тесты
- Скрипты для метрик и валидации
