## 20:05
Буфер/вставка (Ctrl+V) и harness-ошибка "command output pipes did not close after 1s": причина — xclip при `echo| xclip` держит унаследованный stdout harness'а и закрывается слишком рано, потеряв selection. РЕШЕНИЕ навсегда: хелпер ~/.local/bin/clip (в PATH). Использование: clip "текст" или clip -f /file. Внутри: ( cat "$tmp" | xclip -selection clipboard ) </dev/null >/dev/null 2>&1 &  + ( sleep 8; pkill xclip ) &. ВАЖНО: не писать двойное перенаправление stdin (<file и </dev/null) — второе перебивает первое, xclip читает пусто. После clip жди ~0.5-1с, затем xdotool key ctrl+v.
