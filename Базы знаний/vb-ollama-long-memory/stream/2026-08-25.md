## Как повторить изменения потом (рецепт)
1. Репозиторий: `/home/voron/Документы/VB-ollama/GitHub ollama/ollama 0.33.0-rc3`.
2. Свои правки: `git status --short` — видны agent/tools/file.go, file_test.go, memory.go (new), cmd/agent_tui.go и др. Полный список и diff: `git diff` / `git diff --stat`.
3. Откат всего: `git checkout -- agent/tools/ cmd/` + удалить untracked memory.go.
4. Тесты: `go test ./agent/tools/ -count=1`; vet: `go vet ./agent/tools/ ./cmd/`.
5. Сборка + установка (mv, не cp!):
   ```bash
   go build -ldflags "-X github.com/ollama/ollama/version.Version=0.33.0-rc3" -o /tmp/ollama-patched .
   sudo mv /tmp/ollama-patched /usr/local/bin/ollama && sudo chmod 755 /usr/local/bin/ollama
   ```
6. Рестарт TUI (новое окно konsole или restart_self.sh) — старые процессы не трогаем, mv атомарно меняет inode.
7. Проверка: в TUI `/prompt` → tools: 6 (bash/read/edit/write/memory/skill).
