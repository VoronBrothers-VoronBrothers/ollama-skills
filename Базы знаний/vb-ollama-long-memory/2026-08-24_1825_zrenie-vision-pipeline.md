# Зрение оркестратора: свернуть → скриншот → развернуть → вставить

Дата/время: 2026-08-24 ~18:16.

## Вывод (зафиксировано пользователем)
Такой способ **подходит для создания «зрения»**: оркестратор видит экран через скриншот, вставленный в свой чат.

## Рабочий конвейер (в фоне, nohup + лог в /tmp)
Скрипты: /home/voron/Документы/VB-ollama/Скрипты_ИИ
1. `win_id.sh` — ID своего окна (поиск `--name 'ollama$'`, якорь в конце — иначе ловит Dolphin vb-ollama-long-memory)
2. `win_min.sh $ID` — свернуть (экран остаётся свободен для снимка других окон)
3. `screenshot.sh` — PNG 1920x1080 в /tmp + путь файла в буфер обмена (spectacle -b -f -n)
4. `win_restore.sh $ID` — развернуть
5. `windowactivate $ID`
6. `press_esc.sh` → `press_paste.sh` (Ctrl+Shift+V вставляет скриншот-путь/картинку в ollama TUI) → `press_enter.sh`
7. Проверка: `cat /tmp/win_seq*.log`; буфер: `xclip -o -selection clipboard`

## Нюансы
- Все последовательности — отдельным bash-файлом + nohup в фоне, чтение лога через sleep; не цепочкой `&&` в одном вызове (оркестратор режет).
- xdotool search находит окна и при свёрнутом состоянии — ID стабилен.
- «command output pipes did not close after 1s» — не ошибка, фоновый процесс работает.
