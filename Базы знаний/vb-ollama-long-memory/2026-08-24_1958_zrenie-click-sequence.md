# Протокол: зрение → координаты → клик (последовательность)

Дата/время: 2026-08-24 ~19:58.

## Протокол (рабочий, подтверждён пользователем)
1. **Сначала зрение в фоне:** `cd Скрипты_ИИ && ./bg-run.sh ./зрение.sh` → ждать ~12 сек, картинка приходит в чат.
2. **Я смотрю скриншот, определяю координаты**, передаю пользователю (или сразу кликаю).
3. **Клик в переднем плане:** `python3 click_xy.py X Y 0.5` (НЕ через bg-run.sh — не срабатывает, см. записку 2026-08-24_1950).

## Нюансы
- Комбинация «зрение + sleep 12 + клик» в ОДИН вызов не прокатывает: harness отменяет команду на sleep (лимит 180с/вывод не закрывается) — пользователю приходилось кликать вручную.
- `zrenie_click.sh` (Скрипты_ИИ) лежит как обёртка, но только для СЛУЧАЯ ИЗВЕСТНЫХ ЗАРАНЕЕ координат.
- Правильный рабочий цикл: два отдельных вызова — зрение, потом по картинке клик с переданными координатами.

## Скрипт ку-ку.sh (Скрипты_ИИ/ку-ку.sh)
«Прятки»: после клика (если фокус ушёл на другое окно, например Chrome) вернуть своё окно оркестратора на передний план + фокус.
- Ищет окно по `xdotool search --name 'ollama$'`, затем windowraise/windowfocus/windowactivate.
- Запуск: `./bg-run.sh ./ку-ку.sh` (в фоне, логи в /dev/null).
