# Отключение web_search / web_fetch в промте TUI

Дата/время: 2026-08-23 ~21:30 (зафиксировано 2026-08-24 04:31)

## Что сделано
Инструменты web_search и web_fetch убирали из промта TUI переменной окружения
OLLAMA_AGENT_DISABLE_WEBSEARCH (читается cmd/agent_tui.go:268 — инструменты
регистраются, только если переменная пуста). Задана =1 в двух местах:

1. ~/.zshrc (строка 125):
   export OLLAMA_AGENT_DISABLE_WEBSEARCH=1
2. Скрипты_ИИ/ollama_console.sh (строка 27) — префикс команды:
   CMD="OLLAMA_AGENT_DISABLE_WEBSEARCH=1 ollama"

Автозапуск идёт через systemd user service ollama-console.service → ollama_console.sh,
поэтому цепочка закрывает и новые сессии, и рестарты.

Проверено: в TUI /prompt → tools: 4 (bash/read/edit/skill), web_* отсутствуют.
Скрин: /tmp/prompt_ok_1787509913.png

## Как вернуть исходное состояние (включить web_search/web_fetch)
1. Удалить строку `export OLLAMA_AGENT_DISABLE_WEBSEARCH=1` из ~/.zshrc (строка 125).
2. В Скрипты_ИИ/ollama_console.sh вернуть строку 27 к виду: CMD="ollama"
3. Перезапустить TUI (или перезагрузиться — автозапуск подхватит новое).
Проверка: /prompt → tools: 6, web_search и web_fetch на месте.

Вариант «на время» без правки файлов: в окне konsole сделать
`unset OLLAMA_AGENT_DISABLE_WEBSEARCH` и запустить ollama вручную.
