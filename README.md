# ollama-skills

Скиллы Ollama (SKILL.md) для локального ИИ-оркестратора.

| Скилл | Назначение |
|---|---|
| edit-tool | Правильное использование инструмента edit (точечные правки) |
| gui-input | Управление мышью/клавиатурой в GUI-приложениях |
| model-boot-switch | Смена кванта/модели оркестратора и перезапуск TUI |
| ollama-safe-call | Безопасный вызов локальных Ollama-моделей (bg + polling) |
| quant-cascade | Эскалация квантов (iq3→q8) и деградация обратно |
| save-session | Память между сессиями, чекпоинты, самовозобновление |
| screenshot | Скриншоты рабочего стола/окон и визуальная проверка |

- ModelFile оркестратора системы, по умолчанию qwen3.8

Установка: скопировать каталоги в `~/.ollama/skills/`.
